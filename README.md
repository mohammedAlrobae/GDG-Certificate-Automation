🎓 GDG Certificate Automation Tool
The official automated solution for GDG Chapter Leaders to generate event certificates in bulk.

🌟 Overview
Generating certificates manually is a tedious task. This tool is designed to help Google Developer Groups leaders automate the process:

📊 Bulk Generation: Upload an Excel/CSV roster and generate hundreds of certificates in seconds.

🎯 Visual Positioning: Perfectly place participant names on your template using a coordinate system.

🔒 Secure & Private: No data is stored; all processing happens in-memory during your session.

🚀 How to Use
1️⃣ Direct Access (No Installation)
The fastest way to use the tool. Simply click the link below and start generating:
👉 https://gdg-certificate-automation.streamlit.app

2️⃣ Docker (Local Container)
For leaders who prefer running the tool locally or in an isolated environment, use our official Docker image:

Bash
# Pull and run the tool in one command
docker run -p 8501:8501 mohammedrobae/gdg-cert-app:v1
After running, open your browser at: http://localhost:8501

🔑 Access Control
To ensure authorized use, the tool requires a Regional Access Key.

Please use your assigned chapter key to unlock the dashboard.

If you don't have a key, please contact the project administrator.
